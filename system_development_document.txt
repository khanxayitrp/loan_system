# เอกสารสรุประบบและแนวทางการพัฒนาระบบ (System Development Document)

**ชื่อโครงการ:** Financial Loan & E-Commerce Platform (loan_system)
**ประเภทระบบ:** Enterprise SaaS / Loan Management / E-Commerce / AI Platform
**เวอร์ชันเอกสาร:** 1.0

---

## 1. ภาพรวมระบบ (System Overview)

ระบบนี้เป็นแพลตฟอร์มการบริหารจัดการสินเชื่อ (Loan Management System) รวมกับแพลตฟอร์มอีคอมเมิร์ซ (E-Commerce Platform) ระดับองค์กร ออกแบบขึ้นเพื่อรองรับการทำงานของ สินเชื่อ, การประเมินความเสี่ยง, การสมัครสมาชิกองค์กร, การอนุมัติสัญญา, การรับชำระเงิน, การออกเอกสาร PDF สัญญา และการเชื่อมต่อกับระบบภายนอก เช่น Lao Telecom (SOAP/OTP API) และบริการ AI

---

## 2. สถาปัตยกรรมและเทคโนโลยีที่ใช้ (Architecture & Tech Stack)

### 2.1 Backend Technology Stack
* **Language & Runtime:** Node.js, TypeScript (ES2022+)
* **Framework:** Express.js (REST API, Modular Routing)
* **ORM & Database:** Sequelize ORM (TypeScript models), MySQL / MariaDB (Primary Database)
* **Cache & Memory Management:** Redis (Caching, Rate Limiting storage, Session/OTP)
* **Real-time Communication:** Socket.io
* **Background Jobs & Tasks:** `node-cron` (Daily Tracking, Payment Reminders, Table Partitioning)
* **API Documentation:** Swagger UI / OpenAPI 3.0 (`swagger-jsdoc`, `/api-docs`)

### 2.2 Security & System Operations
* **Security:** Helmet, CORS, Express Rate Limit, Cookie Parser
* **Authentication:** JWT Access Token & Refresh Token Rotation, Password Hashing via `bcryptjs`
* **File Upload & PDF:** Multer, AWS S3 SDK (`@aws-sdk/client-s3`), Puppeteer, Handlebars, Sharp
* **Integrations:** Lao Telecom SOAP Client (`soap`), Encryption utilities (`encrypt.jar` / `decrypt.jar`), Google Generative AI (`@google/generative-ai`)

## 4. โมดูลหลักของระบบ (Core System Modules)

### 4.1 ระบบยืนยันตัวตนและการจัดการสิทธิ์ (Authentication & Authorization)
* **User & Auth Management (`auth.routes.ts`, `user.routes.ts`):** รองรับระบบ Login, Logout, Refresh Token Rotation และ Token Blacklist
* **Role-Based Access Control (`permission.routes.ts`):** กำหนดสิทธิ์ผู้ใช้งานตามฟีเจอร์ (Feature Permissions) และบทบาท (RBAC)

### 4.2 ระบบจัดการข้อมูลลูกค้าและประวัติเครดิต (Customer & CIB Profile)
* **Customer Profile (`customer.routes.ts`):** จัดเก็บข้อมูลส่วนตัว, ที่อยู่ (`customerLocation.routes.ts`), ข้อมูลการทำงาน (`customer_work_info`)
* **CIB Credit Profile (`customer_cib_profiles`, `customer_cib_debts`):** ดึงและวิเคราะห์ข้อมูลภาระหนี้ CIB จากระบบตรวจสอบสินเชื่อ

### 4.3 ระบบจัดการสินเชื่อและการอนุมัติ (Loan Application & Management)
* **Loan Application (`loan-application.routes.ts`):** ยื่นคำขอสินเชื่อ, ตรวจสอบสถานะคำขอ
* **Verification Process (`loan_basic_verifications`, `loan_call_verifications`, `loan_field_visits`):**
  * Basic Verification: ตรวจสอบเอกสารเบื้องต้น
  * Call Verification: บันทึกข้อมูลการโทรสอบถาม
  * Field Visit: บันทึกข้อมูลการลงพื้นที่ตรวจสอบ
* **Income Assessment & Scoring (`loan_income_assessments`, `credit_scoring_rules`):** ประเมินรายได้และคำนวณคะแนนความเสี่ยง
* **Approval Workflow (`loan_approval_logs`):** บันทึกประวัติการพิจารณาอนุมัติคำขอสินเชื่ออย่างละเอียด
* **Loan Contract & Restructuring (`loan_contract.routes.ts`, `loan-restructure.routes.ts`):** สร้างสัญญาเงินกู้, การปรับโครงสร้างหนี้, การขอเปลี่ยนแปลงเงื่อนไขสัญญา

### 4.4 ระบบสมาชิกและการลงทะเบียนวงเงิน (Membership Origination & Credit System)
* **Membership Application (`membership-origination.routes.ts`):** การสมัครสมาชิกเพื่อขอวงเงินสินเชื่อ
* **Credit Purpose (`credit-purpose.routes.ts`):** จัดการวัตถุประสงค์การกู้ยืม
* **Credit Accounts & Ledger (`credit_accounts`, `credit_ledger`):** จัดการวงเงินสินเชื่อ, บันทึกการเคลื่อนไหวของวงเงิน (Ledger), แจ้งเตือนความเสี่ยง (`credit_risk_alerts`)

### 4.5 ระบบอีคอมเมิร์ซและพันธมิตร (E-Commerce & Partner Network)
* **Partners & Shops (`partner.routes.ts`):** จัดการข้อมูลร้านค้าพันธมิตร
* **Products & Categories (`product.routes.ts`, `global_categories.routes.ts`):** จัดการสินค้า, ประเภทสินค้า, รูปภาพสินค้า (`product_gallery`), ตัวเลือกสินค้า (`product_variants`)
* **Orders & Cart (`orders`, `carts`):** ตระกร้าสินค้า, คำสั่งซื้อสินค้าผ่อนชำระ
* **Delivery Receipt (`delivery_receipt.routes.ts`):** ใบส่งมอบสินค้าและยืนยันการรับสินค้า

### 4.6 ระบบการชำระคืนและการเงิน (Repayments & Financial Operations)
* **Repayment Schedule (`repayment.routes.ts`, `repayment_schedules`):** คำนวณตารางผ่อนชำระ (Amortization Builder) ทั้งแบบลดต้นลดดอกและแบบฟิกซ์
* **Repayment Operations (`repayments`, `payment_transactions`):** บันทึกการรับชำระเงิน, ออกหลักฐานการชำระ, อัปเดตยอดคงเหลือ

### 4.7 ระบบ OTP และการเชื่อมต่อ Lao Telecom (OTP & Telecommunication)
* **Lao Telecom SOAP Integration (`laotelecom.service.ts`):** เชื่อมต่อ SOAP Service ของ Lao Telecom สำหรับส่ง SMS OTP
* **Encryption Layer (`ltc-encrypt.ts`, Java Jar Utils):** เข้ารหัสข้อมูลลับสำหรับการส่งผ่าน SOAP Webservice
* **OTP Service (`otp.service.ts`, `otp.routes.ts`):** ส่ง OTP, ยืนยัน OTP, Resend, และเก็บสถานะลงใน Redis/In-Memory Storage

### 4.8 ระบบออกเอกสารสัญญา PDF (PDF Generation)
* **PDF Service (`pdf.service.ts`, `pdf.routes.ts`):** แปลง Handlebars Template เป็นสัญญา PDF โดยใช้ Puppeteer Rendering Engine
* **Support Documents:** สัญญาเงินกู้, ใบรับสินค้า, หนังสือมอบอำนาจ, สัญญาค้ำประกัน

### 4.9 ระบบงานเบื้องหลังอัตโนมัติ (Background Cron Jobs)
* **Daily Tracking Service (`DailyTrackingService.ts`):** คำนวณยอดค้างชำระ, ดอกเบี้ย และสถานะหนี้รายวัน
* **Reminder Cron Service (`ReminderCronService.ts`):** ส่งการแจ้งเตือนชำระเงินเมื่อใกล้ถึงกำหนด
* **Partition Service (`partition.service.ts`):** บริหารจัดการการแบ่งพาร์ทิชันตารางในฐานข้อมูลอัตโนมัติ

## 5. ตารางฐานข้อมูลหลัก (Core Database Tables Summary)

1. **`users` / `user_permissions` / `features`:** จัดเก็บข้อมูลผู้ใช้งานระบบและสิทธิ์การเข้าถึง
2. **`customers` / `customer_locations` / `customer_work_info`:** ข้อมูลลูกค้า
3. **`customer_cib_profiles` / `customer_cib_debts`:** ประวัติและภาระหนี้ CIB
4. **`membership_applications` / `membership_tiers` / `membership_decisions`:** ข้อมูลการสมัครและระดับสมาชิก
5. **`credit_accounts` / `credit_limit_applications` / `credit_ledger`:** วงเงินสินเชื่อและบันทึกบัญชีวงเงิน
6. **`loan_applications` / `loan_contract` / `loan_approval_logs`:** ข้อมูลการยื่นกู้ สัญญา และประวัติอนุมัติ
7. **`loan_basic_verifications` / `loan_call_verifications` / `loan_field_visits`:** ข้อมูลการตรวจสอบ
8. **`repayment_schedules` / `repayments` / `payment_transactions`:** ตารางผ่อนชำระและการชำระเงิน
9. **`partners` / `products` / `product_variants` / `orders` / `delivery_receipts`:** ระบบพันธมิตรและสินค้า
10. **`audit_logs` / `notifications`:** บันทึกการทำงานของระบบและการแจ้งเตือน

## 6. เส้นทาง API หลัก (Main API Endpoints)

* **`/api/auth`**: Endpoints ยืนยันตัวตน (`/login`, `/refresh`, `/logout`)
* **`/api/users` / `/api/permissions`**: จัดการผู้ใช้งานและสิทธิ์
* **`/api/customer` / `/api/customer-locations`**: จัดการข้อมูลลูกค้าและตำแหน่ง
* **`/api/membership` / `/api/membership-purposes`**: ระบบสมัครสมาชิกองค์กรและวงเงิน
* **`/api/loan-application`**: การยื่นคำขอสินเชื่อและการประเมิน
* **`/api/loan-contract` / `/api/loan-restructure`**: สร้างสัญญาเงินกู้และการปรับโครงสร้างหนี้
* **`/api/repayments`**: การคำนวณตารางชำระและรับชำระเงิน
* **`/api/shops` / `/api/products` / `/api/productTypes`**: ระบบพันธมิตรร้านค้าและสินค้า
* **`/api/otp`**: ส่งและตรวจสอบรหัส OTP SMS
* **`/api/pdf`**: สร้างเอกสารสัญญา PDF
* **`/api/dashboard` / `/api/reports` / `/api/admin`**: รายงาน สถิติ และระบบผู้ดูแล

## 7. ข้อกำหนดความปลอดภัยและการพัฒนา (Security & Engineering Guidelines)

1. **Data Security & Privacy:** เข้ารหัสข้อมูลสำคัญ (PII), ห้ามพิมพ์ข้อมูลลับหรือ OTP ลงใน Console/Logs
2. **Database Integrity:** การทำธุรกรรมทางการเงิน (Financial Operations) ต้องใช้งาน Database Transactions (`sequelize.transaction()`) เสมอ
3. **API Design Standard:** ใช้คำตอบรูปแบบมาตรฐาน JSON
   ```json
   {
     "success": true,
     "message": "OK",
     "data": {}
   }
   ```
4. **Backward Compatibility:** ห้ามเปลี่ยนชื่อฟิลด์ API Response เดิม เพื่อป้องกันผลกระทบกับแอปพลิเคชันมือถือหรือระบบภายนอก
5. **Rate Limiting:** จำกัดจำนวนคำขอสำหรับ API ที่มีความเสี่ยง เช่น Auth Login (`authLimiter`) และ PDF/Heavy Operations (`heavyTaskLimiter`)
